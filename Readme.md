# Global AI Adoption in Education

## Project Overview

Global AI Adoption in Education is a Tableau-based data visualization project that analyzes the adoption of Artificial Intelligence in the education sector across different regions and countries.

The project uses the **Global AI in Education dataset** to explore patterns and trends related to AI adoption in education. Tableau was used to transform the raw data into interactive visualizations, a dashboard, and a Story.

The project also includes a web-integrated version deployed using **Vercel**, making the project accessible through a web browser.

## Objectives

- Analyze the adoption of Artificial Intelligence in education.
- Explore AI adoption patterns across different regions and countries.
- Identify important trends and patterns in AI adoption.
- Present the analysis through interactive Tableau visualizations.
- Create an interactive Tableau dashboard.
- Present insights through a Tableau Story.
- Provide a web-based interface for the project.

## Dataset

The project uses the following dataset:

**Dataset:** Global AI in Education (5).csv

The dataset was used as the primary source for performing the analysis and creating the Tableau visualizations.

## Visualizations

The project includes multiple Tableau visualizations for analyzing global AI adoption in education.

These visualizations are combined into an interactive Tableau Dashboard to provide a comprehensive view of the analysis.

## Interactive Dashboard

The dashboard combines the major visualizations into a single interactive interface.

It allows users to explore the available AI adoption data and understand patterns and trends in education through visual analysis.

## Tableau Story

The Tableau Story presents the analysis in a structured and comprehensive format.

The Story is titled:

**Global AI Adoption in Education: A Comprehensive Global Analysis**

It presents the major findings and visual analysis of AI adoption in education.

## Web Integration

A web-based interface was created to provide easy access to the project through a browser.

The web application provides access to the project and its data visualization analysis through a publicly available web interface.

The web application is deployed using **Vercel**.
